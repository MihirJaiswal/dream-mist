title: Limits and defaults
description: Every number that matters when you build, in one table.
---

## Maps

| What                     | Value                                                |
| ------------------------ | ---------------------------------------------------- |
| Tile size                | 16 × 16 pixels                                       |
| Map size                 | 6 to 128 tiles wide and tall                         |
| New empty city           | 40 × 30 tiles                                        |
| New interior             | 14 × 10 tiles, walls around, exit door at the bottom |
| Interiors per city       | 40                                                   |
| Built-in tileset         | 6,328 Hoenn tiles                                    |
| Hoenn maps to start from | 60                                                   |
| Cities per account       | 50                                                   |

## People

| What                  | Value                                                               |
| --------------------- | ------------------------------------------------------------------- |
| Name                  | Up to 24 characters                                                 |
| Wandering range       | 2 tiles from where they were placed                                 |
| Path speed            | 3 tiles a second walking, 6 running, pause 0 to 10 seconds per stop |
| Trainer line of sight | 4 tiles ahead                                                       |
| Trainer team          | 1 to 6 Pokémon, levels 1 to 100                                     |
| Reward                | One Pokémon, up to 99 Poké Balls and 99 Potions                     |

## Wild Pokémon

| What                    | Value                                                                               |
| ----------------------- | ----------------------------------------------------------------------------------- |
| Available species       | 1,025 (every generation, Bulbasaur to Pecharunt)                                    |
| Encounter rate          | 1% to 40% per step                                                                  |
| Default tall grass zone | Zigzagoon and Wurmple (Lv 2 to 4), Poochyena (Lv 3 to 4), Ralts (Lv 3 to 5), at 12% |
| Shiny chance            | 1 in 128                                                                            |

## Player

| What                 | Value                                            |
| -------------------- | ------------------------------------------------ |
| Starters             | Treecko, Torchic, Mudkip at level 5              |
| Starting bag         | 10 Poké Balls, 5 Potions                         |
| Party                | 6, the rest goes to the PC box                   |
| Walking speed        | 4 tiles per second, 8 when running               |
| Potion               | Restores 20 HP                                   |
| Nurse                | Full heal, Poké Balls and Potions topped up to 5 |
| Beating a trainer    | 2 Poké Balls                                     |
| Beating a Gym Leader | A badge and 5 Poké Balls                         |
| Losing               | Healed, back to the map's spawn point            |

## Uploads

| What           | Value                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------- |
| Tileset image  | PNG, WebP, AVIF or GIF, tiles of 16 to 64 pixels. Up to 4 MB with an account, 512 KB without.     |
| Music          | mp3, m4a, ogg, wav, webm or aac. Up to 12 MB, account needed.                                     |
| Person sprite  | 3×4 frames of 16×32 px (48×128), or RPG Maker sheets. Up to 1 MB with an account, 256 KB without. |
| Pokémon sprite | One image, 64×64 px ideal, 256×256 at most. Up to 1 MB with an account, 256 KB without.           |
| City name      | Up to 40 characters                                                                               |
