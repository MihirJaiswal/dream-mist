---
title: Keyboard shortcuts
description: Every shortcut in the editor and in play mode.
---

On Windows and Linux, use <kbd>Ctrl</kbd> instead of <kbd>⌘</kbd>.

## Tools

| Shortcut | Action |
| --- | --- |
| <kbd>B</kbd> | Brush |
| <kbd>E</kbd> | Eraser |
| <kbd>R</kbd> | Rectangle |
| <kbd>F</kbd> | Fill |
| <kbd>I</kbd> | Picker |
| <kbd>S</kbd> | Select |

## Layers

| Shortcut | Layer |
| --- | --- |
| <kbd>1</kbd> | Ground |
| <kbd>2</kbd> | Objects |
| <kbd>3</kbd> | Above |
| <kbd>4</kbd> | Collision |
| <kbd>5</kbd> | Encounters |
| <kbd>6</kbd> | Story |
| <kbd>7</kbd> | Doors |
| <kbd>8</kbd> | People |
| <kbd>9</kbd> | Spawn |

## Editing

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>Z</kbd> | Undo |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> | Redo |
| <kbd>⌘</kbd> <kbd>C</kbd> | Copy the selection |
| <kbd>⌘</kbd> <kbd>X</kbd> | Cut the selection |
| <kbd>⌘</kbd> <kbd>V</kbd> | Paste (click to place, repeat as needed) |
| <kbd>Delete</kbd> | Clear the selection, or remove the selected person |
| <kbd>Esc</kbd> | Stop pasting or placing |

## View

| Shortcut | Action |
| --- | --- |
| <kbd>+</kbd> / <kbd>−</kbd> | Zoom in, zoom out |
| <kbd>Ctrl</kbd> + scroll, pinch | Zoom under the cursor |
| <kbd>0</kbd> | Fit the map on screen |
| <kbd>G</kbd> | Toggle the grid |
| <kbd>Space</kbd> + drag, right-drag, two-finger swipe | Pan |

## Testing

| Shortcut | Action |
| --- | --- |
| <kbd>P</kbd> | Play from the tile under the cursor (from the spawn when the cursor is off the map) |
| Right-click a tile | Menu: **Play from here**, or make visitors arrive there |

## Play mode

| Shortcut | Action |
| --- | --- |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd>, arrow keys | Walk |
| <kbd>Shift</kbd> | Run |
| <kbd>Space</kbd>, <kbd>Enter</kbd>, <kbd>Z</kbd>, <kbd>E</kbd> | Talk, read, continue |
| <kbd>1</kbd> to <kbd>4</kbd> | Pick a battle option |
