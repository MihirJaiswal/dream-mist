---
title: Keyboard shortcuts
description: Every shortcut in the editor and in play mode.
---

On Windows and Linux, use <kbd>Ctrl</kbd> instead of <kbd>⌘</kbd>. Press <kbd>?</kbd> in the editor to see this list anytime.

## Anywhere

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>K</kbd> or <kbd>⌘</kbd> <kbd>F</kbd> | Search actions, tools, layers, stamps, maps and people |
| <kbd>⌘</kbd> <kbd>S</kbd> | Save now (towns also save on their own as you build) |
| <kbd>⌘</kbd> <kbd>Enter</kbd> | Switch between Build and Play |
| <kbd>⌘</kbd> <kbd>\\</kbd> | Hide or show the panels, to see just the map |
| <kbd>?</kbd> | Show all shortcuts |

## Tools

| Shortcut | Action |
| --- | --- |
| <kbd>B</kbd> | Brush |
| <kbd>E</kbd> | Eraser |
| <kbd>X</kbd> | Swap between brush and eraser |
| <kbd>R</kbd> | Rectangle |
| <kbd>F</kbd> | Fill |
| <kbd>I</kbd> | Picker |
| <kbd>S</kbd> | Select |
| <kbd>Alt</kbd> + click | Pick the tile under the cursor as the brush, without switching tools |

## Painting

| Shortcut | Action |
| --- | --- |
| <kbd>Shift</kbd> + drag | Paint a straight line (it follows the direction you drag most) |
| <kbd>Shift</kbd> + erase | Erase every tile layer of the square at once |

| <kbd>1</kbd> | Ground |
| <kbd>2</kbd> | Objects |

| <kbd>4</kbd> | Collision |

| <kbd>6</kbd> | Story |
| <kbd>7</kbd> | Doors |
| <kbd>8</kbd> | People |
| <kbd>9</kbd> | Spawn |

## Selection

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>A</kbd> | Select the whole map |
| <kbd>⌘</kbd> <kbd>C</kbd> | Copy the selection |
| <kbd>⌘</kbd> <kbd>X</kbd> | Cut the selection |
| <kbd>⌘</kbd> <kbd>V</kbd> | Paste (click to place, repeat as needed) |
| <kbd>⌘</kbd> <kbd>D</kbd> | Duplicate the selection next to it (right, below, left or above, wherever it fits). The copy becomes the selection |
| Arrow keys | Move the selection and what's in it by 1 tile, or 5 with <kbd>Shift</kbd> |
| <kbd>Delete</kbd> | Clear the selection, or remove the selected person |
| <kbd>Esc</kbd> | Stop selecting, pasting or placing |

## Overlapping pieces

| Shortcut | Action |
| --- | --- |
| <kbd>]</kbd> | Bring the piece behind to the front, on the square under the cursor and the rest of the overlap |
| <kbd>[</kbd> | Send the front piece to the back |
| Right-click | The same as **Bring to front** and **Send to back** in the menu |

## Editing

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>Z</kbd> | Undo |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> | Redo |

## View

| Shortcut | Action |
| --- | --- |
| <kbd>+</kbd> / <kbd>−</kbd> | Zoom in, zoom out |
| <kbd>Ctrl</kbd> + scroll, pinch | Zoom under the cursor |
| <kbd>⇧</kbd> <kbd>1</kbd> or <kbd>0</kbd> | Fit the whole map on screen |
| <kbd>⇧</kbd> <kbd>2</kbd> | Zoom to the selection |
| <kbd>G</kbd> | Toggle the grid |
| <kbd>Space</kbd> + drag, right-drag, two-finger swipe | Pan |

## Testing

| Shortcut | Action |
| --- | --- |
| <kbd>P</kbd> | Play from the tile under the cursor (from the spawn when the cursor is off the map) |
| Right-click a tile | Menu: **Play from here**, make visitors arrive there, and **Bring to front** / **Send to back** where two pieces overlap |

## Play mode

| Shortcut | Action |
| --- | --- |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd>, arrow keys | Walk |
| <kbd>Shift</kbd> | Run |
| <kbd>Space</kbd>, <kbd>Enter</kbd>, <kbd>Z</kbd>, <kbd>E</kbd> | Talk, read, continue |
| <kbd>1</kbd> to <kbd>4</kbd> | Pick a battle option |
