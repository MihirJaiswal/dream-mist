---
title: City file format
description: What's inside an exported .json city, for backups, scripts and tools.
---

**Export .json** saves the whole city as one JSON file. You can edit it with a script and bring it back with **Import file** in **Your cities**. Missing or broken fields are filled in with defaults on import.

To have an AI agent write a whole game file, see [Make a game with an AI agent](/docs/agents): its guide, [/agents.md](/agents.md), covers this format in depth with a tile catalog and a builder script.

## City

```ts
type City = {
  v: 1;
  id: string;
  name: string; // up to 40 characters
  author: string;
  width: number; // tiles
  height: number;
  layers: {
    ground: number[]; // width × height tile values, row by row
    decor: number[]; // the Objects layer
    above: number[];
  };
  solid: number[]; // 1 = blocked
  behavior: number[]; // tile behaviors, see below (0 = normal)
  zone: number[]; // 0 = none, n = zones[n - 1]
  gate: number[]; // 0 = open, n = the story step whose `n` is n
  zones: Zone[];
  npcs: Npc[];
  spawn: { x: number; y: number };
  doors: Door[];
  triggers: Trigger[]; // event areas that play a script when stepped in
  story: Step[]; // main story and side quest steps, in order within each
  quests: Quest[]; // side quests
  interiors: City[]; // interiors and outdoor maps, same shape, without story, quests, zones, tilesets, music
  outdoor?: boolean; // on an outdoor map (route, town): joined to the region at its edges
  region?: { x: number; y: number }; // its position on the region grid, in tiles (the outside map is at 0, 0)
  tilesets?: Tileset[];
  sprites?: Sprite[]; // custom looks for people and Pokémon
  music?: { town?: string; battle?: string };
  weather?: "rain" | "snow" | "fog" | "sandstorm"; // per map, clear when not set
  time?: "morning" | "evening" | "night" | "clock"; // per map, day when not set; "clock" follows the player's clock
  type?: "outdoor" | "indoor" | "cave"; // per map, picks the automatic battle scene (outdoor for the outside and outdoor maps, indoor for interiors)
  dark?: boolean; // per map: dark until the player has HM05 Flash
  song?: string; // per map: its own music (an uploaded track url), the town music when not set
  rules?: { difficulty?: "easy" | "hard"; caps?: number[] }; // outside map only: trainer difficulty (normal when not set), level caps by badges
  battle?: { image: string; platforms: boolean }; // per map battle background: a picture url, or an Emerald scene "/game/battle/<scene>.png" (tall_grass, long_grass, sand, rock, cave, water, pond_water, underwater, sky, building, stadium); maps without one use the outside map's, then the automatic scene
  updated: number; // timestamp in milliseconds
};
```

Every grid is a flat array of `width × height` numbers. The tile at column `x` and row `y` is at index `y * width + x`.

## Tile values

| Value                         | Meaning                                                |
| ----------------------------- | ------------------------------------------------------ |
| `0`                           | Empty                                                  |
| `1` to `9999`                 | Built-in Hoenn tileset: frame number + 1               |
| `(k + 1) × 10000 + frame + 1` | Frame of the custom tileset at index `k` in `tilesets` |

## Tile behaviors

| `behavior`  | Tile                                                  |
| ----------- | ----------------------------------------------------- |
| `0`         | Normal                                                |
| `1` to `4`  | Ledge jumped down, up, left, right                    |
| `5`         | Surf water (crossed on a Water type, ignores `solid`) |
| `6`         | Ice                                                   |
| `7` to `10` | Push tile moving the player up, down, left, right     |

## Story steps

```ts
type Step = {
  id: string; // used by people's story settings
  quest?: string; // side quest id, main story when not set
  goal?: string; // what the Journal says while it's the next step
  n: number; // used by gate tiles, stays the same when steps are reordered
  name: string;
  blocked: string; // message at the gates
  blocker?: "wall" | "object" | "person";
  tile?: number; // tile drawn on the gates when blocker is "object"
};

type Quest = {
  id: string;
  name: string;
  after?: string; // step id: the quest starts once it's done
};
```

## People

```ts
type Npc = {
  x: number;
  y: number;
  sprite: string; // "" for signs and Pokémon, "custom:<id>" for a custom sprite
  creature?: { species: number; level: number; look?: string }; // a Pokémon on the map, look = custom sprite id
  dir: "up" | "down" | "left" | "right";
  name: string;
  dialogue: string; // an empty line starts a new page
  role: "talk" | "trainer" | "healer" | "wild" | "shop" | "item"; // "wild": a Pokémon to battle and catch, "shop": a Poké Mart clerk, "item": an item ball holding `gift`
  shop?: ItemId[]; // what a clerk sells, everything when not set
  gift?: { item: ItemId; count: number }; // given the first time the player talks to them (or found in an item)
  hidden?: boolean; // an item hidden on the ground instead of a ball
  script?: { actions: Action[]; once: boolean }; // plays instead of their usual part when talked to
  approach?: boolean; // walks up to the player and talks the first time they see them
  wander: boolean;
  path?: {
    points: { x: number; y: number }[]; // stops after where they stand
    loop: boolean; // true: back to the start, false: walk back the same way
    run: boolean;
    pause: number; // seconds at each stop
  };
  trainer?: {
    team: { species: number; level: number; held?: ItemId }[]; // national Pokédex numbers, 1 to 1025, and a held item
    gym: boolean;
    badge: string;
    defeat: string;
  };
  story?: {
    after?: string; // Shows up (step id)
    until?: string; // Leaves
    requires?: string; // Needs first
    locked?: string; // Says until then
    completes?: string; // Talking (or beating them) completes
    done?: string; // Says afterwards
    reward?: { species?: number; level?: number; balls?: number; potions?: number; money?: number };
  };
};

// Sold: "poke-ball" | "great-ball" | "potion" | "super-potion" | "full-heal"
// Key items (given, not sold): "old-rod" | "good-rod" | "super-rod" | "hm-flash"
// Held items: "oran-berry" | "sitrus-berry" | "lum-berry" | "leftovers" | "quick-claw" | "charcoal" | "mystic-water" | "miracle-seed" | "magnet" | "silk-scarf"
type ItemId = string;
```

## Events and scripts

```ts
type Trigger = {
  id: string;
  x: number; // top-left tile of the area
  y: number;
  w: number;
  h: number;
  name: string;
  once: boolean; // plays only the first time, per player
  after?: string; // only once this step is done
  until?: string; // no more once this step is done
  actions: Action[];
};

// `who` is someone's index in the map's `npcs`, or "player"
type Action =
  | { do: "say"; text: string; who?: number } // no `who`: narration
  | { do: "come"; who: number } // notice the player and walk up to them
  | { do: "move"; who: number | "player"; steps: ("up" | "down" | "left" | "right")[] }
  | { do: "face"; who: number | "player"; dir: "up" | "down" | "left" | "right" }
  | { do: "back"; who: number } // walk back to where they stand
  | { do: "wait"; seconds: number } // 0 to 10
  | { do: "battle"; who: number } // a trainer or wild Pokémon of the map, stops the script if the player loses
  | { do: "give"; item: ItemId; count: number }
  | { do: "pokemon"; species: number; level: number }
  | { do: "money"; amount: number }
  | { do: "heal" }
  | { do: "step"; step: string } // complete a story step
  | { do: "warp"; to: string; x: number; y: number }; // map id ("" = outside) and tile, ends the script
```

## Zones, doors and tilesets

```ts
type Zone = {
  name: string;
  rate: number; // 0.01 to 0.4, chance per step (walking and surfing)
  color: number; // editor overlay color, like 0x2ecc40
  creatures: {
    species: number;
    min: number;
    max: number;
    method?: "surf" | "fish"; // walking when not set
    time?: "morning" | "day" | "night"; // any time when not set
    rod?: "good" | "super"; // fishing: the weakest rod that hooks it (any rod when not set)
  }[];
};

type Door = {
  x: number;
  y: number;
  to: string; // interior id, "" for outside, "?" for nowhere yet
  tx: number; // arrival tile, -1 to arrive next to the matching door
  ty: number;
};

type Tileset = {
  id: string;
  name: string;
  url: string; // uploaded file or data: URL
  tile: number; // tile size in pixels
  columns: number;
  rows: number;
};
```

```ts
type Sprite = {
  id: string;
  name: string;
  url: string; // uploaded file or data: URL
  kind: "person" | "pokemon";
  layout?: "dreammist" | "rpgvx" | "rpgxp"; // person sheets
  w: number; // frame size in pixels
  h: number;
};
```

<Callout title="Keep tileset order">
  Custom tile values depend on the tileset's position in `tilesets`. Don't reorder or remove entries, or painted tiles will point to the wrong image.
</Callout>
